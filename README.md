# Final Portfolio – SRDT

## About the Project
This is the improved version of my student portfolio. It was developed using HTML5 and CSS to make the webpage more organized, readable and visually appealing while keeping the design simple and professional.

The project builds upon my basic HTML portfolio by introducing CSS selectors, properties, values, declarations and light background colours.

## Features
- Personal information section
- Centered portfolio heading, profile photo and navigation links
- Education details and academic records table
- School and college hyperlinks
- Links to 10th and 12th marksheets
- Certificates section
- Technical skills and hobbies
- Career objective
- Projects section
- Separate contact page with an HTML form
- Light pastel colours for selected sections
- Black headings and blue hyperlinks
- Simple, clean and student-friendly design

## Technologies Used
- HTML5
- CSS3

## Project Files
- `index.html` – Main portfolio webpage
- `contact.html` – Contact form webpage
- `style.css` – Stylesheet for colours, alignment, spacing, tables and layout
- `profile.jpeg` – Profile photo
- `10th-marksheet.jpeg` – Class 10 marksheet image
- `12th-marksheet.jpeg` – Class 12 marksheet image
- `SIH-internal-certificate.jpeg` – Certificate image
- `Viveka-certificate.jpeg` – Certificate image

## HTML Concepts Used
- HTML5 document structure
- Headings and paragraphs
- Images and hyperlinks
- Absolute and relative links
- Ordered and unordered lists
- Tables and captions
- Semantic elements such as `header`, `main`, `section`, `article` and `footer`
- Forms and input elements

## CSS Concepts Used
- Universal selector
- Element selector
- Group selector
- ID selector
- CSS properties and values
- CSS declarations
- Text alignment
- Background colours
- Font family
- Padding and margins
- Table styling
- Link styling

## Design
The portfolio uses a simple pastel colour palette, including light pink, lavender and light blue. The headings remain black, hyperlinks remain blue, and selected sections have soft background colours to maintain a neat and professional appearance.

## How to Run
1. Download or clone this repository.
2. Keep `index.html`, `contact.html`, `style.css` and the required images in the correct folder.
3. Make sure both HTML files link to `style.css`.
4. Open `index.html` in a web browser or use Live Server in Visual Studio Code.

## Learning Outcome
This project helped me understand how CSS works with HTML5 to improve webpage presentation. I practiced CSS selectors, colours, alignment, spacing and table styling while maintaining the original HTML structure.
